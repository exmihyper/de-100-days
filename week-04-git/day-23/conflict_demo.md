# Разрешение конфликтов в Git

## Как выглядит конфликт в файле


- `<<<<<<< HEAD` — начало блока из текущей ветки
- `=======` — разделитель
- `>>>>>>> feature/name` — конец блока из сливаемой ветки

---

## Как разрешить: пошагово

1. Открой файл с конфликтом в редакторе
2. Найди маркеры `<<<<<<<`, `=======`, `>>>>>>>`
3. Убери их. Оставь один правильный вариант (или объедини оба)
4. Сохрани файл
5. Выполни в терминале:

## Полезные команды

| `git status` | Показывает файлы с конфликтами |
| `git diff` | Показывает конфликтующие блоки построчно |
| `git merge --abort` | Отменяет слияние, возвращает как было до merge |
| `git checkout --ours <файл>` | Взять вариант из текущей ветки |
| `git checkout --theirs <файл>` | Взять вариант из сливаемой ветки |

---

## Когда возникает конфликт

- Обе ветки изменили **одну и ту же строку** в одном файле
- Одна ветка **удалила** файл, другая его **изменила**
- Обе ветки **создали** файл с одинаковым именем, но разным содержимым

---

## Как избежать

- Чаще синхронизируйся с `main`: `git pull origin main`
- Делай короткие ветки — чем меньше живёт ветка, тем меньше конфликтов
- Договаривайся с командой, кто какие файлы трогает
