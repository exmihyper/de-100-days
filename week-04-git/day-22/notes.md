# Мои заметки по Git

## Ветки
- `git branch` — показать все ветки
- `git checkout -b name` — создать и переключиться
- `git checkout main` — переключиться на main
- `git merge name` — слить ветку name в текущую


## Полезные команды
- `git log` — история коммитов
- `git diff` — что изменилось с последнего коммита
- `git status` — текущее состояние
