## Как запустить любой проект

Все проекты самодостаточны. Для Python-проектов:

```bash
cd week-XX-тема/day-YY
poetry install
poetry run python имя_скрипта.py
```

Для проектов с Docker:

```bash
cd week-XX-тема/day-YY
docker compose up
```
