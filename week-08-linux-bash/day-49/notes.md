# День 49: Права доступа и управление процессами

## Права доступа

```
-rw-r--r-- 1 user group 0 Nov 5 10:00 file.txt
```

| Символ | Значение |
|--------|----------|
| `-` | файл (`d` — директория) |
| `rw-` | владелец: чтение, запись |
| `r--` | группа: только чтение |
| `r--` | остальные: только чтение |

**Числа:** r=4, w=2, x=1

| Цифры | Права | Где использовать |
|-------|-------|------------------|
| 644 | `rw-r--r--` | Обычные файлы |
| 755 | `rwxr-xr-x` | Скрипты, директории |
| 600 | `rw-------` | Приватные файлы |
| 700 | `rwx------` | Приватные директории |

```bash
chmod 755 script.sh        # числовой
chmod u+x script.sh        # символьный
chown user:group file      # смена владельца (sudo)
```

## Процессы

```bash
ps aux                     # все процессы
ps aux | grep python       # поиск
top                        # интерактивный монитор (q — выход)

sleep 120 &                # в фоне
$!                         # PID последнего фонового
jobs                       # список фоновых задач
kill PID                   # SIGTERM (мягко)
kill -9 PID                # SIGKILL (принудительно)
nohup sleep 600 &          # переживёт закрытие терминала
```

## Cron

```bash
crontab -l                 # список задач
crontab -e                 # редактировать
```

Пример:
```
* * * * * date >> ~/log.txt   # каждую минуту
0 6 * * * /path/to/script.sh  # каждый день в 6:00
```
