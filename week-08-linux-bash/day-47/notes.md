# День 47: Bash scripting basics

## Shebang
```bash
#!/bin/bash
```
Первая строка любого bash-скрипта. Говорит системе, что это bash.

## Переменные
```bash
name="Иван"      # БЕЗ пробелов вокруг =
echo "Привет, $name"
```

## Ввод
```bash
read -p "Как тебя зовут? " username
echo "Привет, $username"
```

## Условия
```bash
if [ "$age" -lt 18 ]; then
    echo "Ребёнок"
elif [ "$age" -le 65 ]; then
    echo "Взрослый"
else
    echo "Пенсионер"
fi
```

## Сравнения
| Оператор | Значение |
|----------|----------|
| `-eq` | равно (числа) |
| `-ne` | не равно |
| `-gt` | больше |
| `-lt` | меньше |
| `-ge` | больше или равно |
| `-le` | меньше или равно |
| `=` | равно (строки) |
| `!=` | не равно (строки) |

## Циклы
```bash
for i in 1 2 3 4 5; do
    echo "Число: $i"
done

count=1
while [ $count -le 3 ]; do
    echo "Счётчик: $count"
    ((count++))
done
```

## Права на исполнение
```bash
chmod +x script.sh
./script.sh
```
